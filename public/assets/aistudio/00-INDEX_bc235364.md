Golden rules
1. Never commit the API key. Use environment variables.
2. Keep audio clips under 30 seconds for REST STT.
3. Write numbers, money and times as spoken words for TTS.
4. Cite vendor numbers as "reported by Gnani".
5. Get consent before recording or cloning anyone's voice.
